# ISOMANIA
============================
🎬 ISOmania - MP4をDVD ISOに変換するアプリ
============================

■ 使い方（Mac）
----------------------------
1. このフォルダ内の「ISOMANIA.app」をダブルクリックします。
2. ブラウザが開き、変換アプリが起動します。
3. MP4ファイルをアップロードし、「変換する！」を押してください。
4. 変換完了後、ISOファイルをダウンロードできます。

■ 必要環境
----------------------------
- macOS 12以上推奨
- 初回起動時、「セキュリティとプライバシー」から実行許可が必要な場合があります。

■ よくある質問
----------------------------
Q. アプリが開かない
→ Controlキーを押しながら「ISOmania.app」を右クリック → 「開く」を選択してください。

Q. ISOをDVDに焼くには？
→ Finderで空DVDを挿入し、ISOファイルを右クリック → 「ディスクユーティリティで開く」→「ディスクを作成」
